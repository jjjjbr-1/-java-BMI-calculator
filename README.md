# BMI Calculator

## Purpose

A simple Java program that calculates the user's Body Mass Index (BMI) using their weight and height, then displays their health status and suitable advice.

## Features

- Easy to use.
- Calculates BMI automatically.
- Displays the user's BMI category.
- Provides simple health advice.

## Concepts Used

- `Scanner` for reading user input.
- Variables and data types such as `double` and `int`.
- Arithmetic operations for calculating BMI.
- `if`, `else if`, and `else` for checking the BMI category.
- `switch` for displaying advice based on the user's status.
- `System.out.println` for displaying messages.
